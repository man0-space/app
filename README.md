# man0 app

The React app provides Vibe, the React Flow Canvas, workflow conversations, Market and the Earn/Spent dashboards. See the [project overview](https://github.com/man0-space/submission) and [judge walkthrough](https://github.com/man0-space/submission/blob/main/JUDGES.md).

Copy `.env.example` to `.env` and configure the API, Compose and NEAR contract settings. In this directory:

```sh
npm ci
npm run dev
```

Open `http://localhost:4001`. Run `npm run build` to check TypeScript and build the frontend locally.
